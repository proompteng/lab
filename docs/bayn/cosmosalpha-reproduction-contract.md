# CosmosAlpha reproduction contract

Status: incremental configuration audit, November 8, 2026. A passing audit establishes configuration consistency only.

The first increment makes the current comparison's omissions inspectable. It does not repair labels, exercise a mining runtime, approve a launch or establish the paper's reported advantage. The active Graph/Chain study remains a separate exploratory trial.

## Run the audit

```sh
bun packages/scripts/src/bayn/audit-cosmosalpha-study.ts \
  /absolute/path/to/frozen-plan.json \
  /absolute/path/to/site-packages/cosmosalpha
```

The command reads the existing plan, its hashed source manifest, installed source files and hashed TOML configurations. It makes no network requests and starts no processes. It requires one full Graph, one MCTS and one gamma-zero Graph configuration for every planned seed. Architecture comes from TOML, not the arm label. A differently named Graph config cannot stand in for MCTS.

It compares data, universe, return convention, preprocessing, operators, proposal settings, evaluation, prompt configuration, model settings and Qlib providers across the study. Within a Graph/no-Flow pair, only gamma and the storage root may differ. Native attempt, iteration and cycle counts remain separate units. Configured proposal maxima do not include proof of initialization overrides, realized calls or usable-factor counts.

Exit 0 means `configuration-consistent`. Exit 1 reports a mismatch or invalid input. Neither exit supplies native config admission, MCTS method parity, data correctness, comparable realized budgets, downstream performance or trading authority. The command is an audit, not a launcher or a mandatory wrapper around existing runners.
