# PR checklist

- [ ] Exact local branch and HEAD recorded
- [ ] Only owned paths staged
- [ ] Conventional Commit and matching PR title
- [ ] Repository PR template filled with no placeholders
- [ ] Focused local validation recorded
- [ ] Remote PR head matches the tested and reviewed commit
- [ ] Required exact-head checks are green
- [ ] Actionable review threads are handled
- [ ] Rollout impact documented for infrastructure changes
- [ ] Squash merge authorized and bound to the verified head; branch deletion omitted
