# Original art and audio

The tug, cargo, asteroids, station, starfield, icon, and sound cues are original procedural assets implemented for Orbit Salvage. Their source lives alongside the game scripts.

The Godot engine is distributed under the MIT license. Its license notice is included in `Godot-LICENSE.txt` and packaged with the exports.

Typography uses Space Grotesk by Florian Karsten and DM Mono by Colophon Foundry, distributed under the SIL Open Font License. The original license files accompany each font in `fonts/`.

- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- DM Mono: https://github.com/google/fonts/tree/main/ofl/dmmono
