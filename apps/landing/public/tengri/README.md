# Desktop wallpaper

`wallpaper.webp` is the dark image (frame 1) from Apple's **Big Sur Graphic** desktop picture. The original artwork is
copyright Apple Inc. The asset is bundled locally; the desktop does not contact a wallpaper service.

- Catalog: <https://mesu.apple.com/assets/macos/com_apple_MobileAsset_DesktopPicture/com_apple_MobileAsset_DesktopPicture.xml>
- Original archive: <https://updates.cdn-apple.com/2025/mobileassets/072-29818/74AF556A-DC02-429B-894B-23AB61E2A5F9/com_apple_MobileAsset_DesktopPicture/2d33861f84f21757db8d5cc656ae09b1143a2c73.zip>
- Retrieved September 5, 2026. Extracted `AssetData/Big Sur Graphic.heic` with macOS ImageIO, selected its dark frame,
  converted to sRGB, and encoded at 3200 × 3200 as WebP quality 90 with Sharp. No artwork was redrawn.

Application icon sources are documented in [icons/README.md](icons/README.md).
