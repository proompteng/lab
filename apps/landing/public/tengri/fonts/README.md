# Desktop code font

Tool output uses the unmodified JetBrains Mono Regular webfont, served from the same origin. Bundling the font
keeps code columns and common output symbols aligned regardless of the fonts installed on the host.

- Source: [JetBrains Mono v2.304](https://github.com/JetBrains/JetBrainsMono/blob/v2.304/fonts/webfonts/JetBrainsMono-Regular.woff2)
- License: [SIL Open Font License 1.1](./OFL.txt), retained from the same release.
- SHA-256: `a9cb1cd82332b23a47e3a1239d25d13c86d16c4220695e34b243effa999f45f2`

The CSS family alias `JetBrains Mono Desktop` isolates this face from the marketing page's Google Fonts stylesheet.
